# HOW THE SYSTEM WORKS

## FROM THE FUEL TANK TO YOUR SCREEN

Nebsam Fuel Monitoring Solution combines **high-precision IoT fuel sensors, GPS tracking technology, and cloud-based monitoring software** to give fleet managers a complete picture of fuel activity.

### STEP 01 — INSTALL

A high-precision IoT fuel sensor is installed inside the vehicle's fuel tank.

### STEP 02 — MEASURE

The sensor continuously measures the fuel level inside the tank.

### STEP 03 — LOCATE

GPS technology records the vehicle's location and movement.

### STEP 04 — TRANSMIT

Fuel and vehicle data is securely transmitted to the Nebsam cloud platform.

### STEP 05 — MONITOR

Fleet managers access the information through the **web dashboard or mobile application**.

### RESULT

**Every fuel movement can be connected to a time, location, vehicle, and quantity—giving you unprecedented visibility over fleet fuel.**

## THE HARDWARE CHAIN

Fuel monitoring is a chain of four elements. Each one is a point of failure and a point of cost, so the page should describe all four rather than presenting the system as a single box.

### 01 — FUEL LEVEL SENSOR

An IoT-based sensor recognises the fuel level in the tank automatically. By measuring fuel volume precisely, it detects tank fill-up and fuel draining volumes **continuously**, rather than at intervals — which is what makes a siphoning event visible as an event rather than as an unexplained difference between two readings.

### 02 — DFM FUEL FLOW METER

Measures fuel actually consumed by the engine, as distinct from fuel level in the tank. Level and flow answer different questions: level tells you what is in the tank, flow tells you what the engine burned.

### 03 — IoT GATEWAY

Fitted to the vehicle. Collects sensor data and transmits it onward.

### 04 — CLOUD SERVER AND DASHBOARD

Data is sent to a cloud-based server through the IoT gateway and monitored in a KPI dashboard.

### THE GPS LAYER

A GPS tracker locates the vehicle in real time and, critically, **records where refuelling and draining events occur**. Fuel data without location tells you that fuel disappeared; fuel data with location tells you where.

---

## THE DASHBOARD

Integrated with the analytics software, the dashboard generates reports on all fuel fillings and possible fuel thefts, each carrying:

## REPORTS

| Report | What it contains |
|---|---|
| **Monthly fuel consumption** | Graphical report on fuel volume change in the vehicle's tank within a selected time interval |
| **Mileage** | Graphical report on fleet fuel efficiency, from fuel consumed measured against distance travelled |
| **Fuel drain** | Statistical table of drain events — quantity of events and total volume of fuel drained from the tank |
| **Fuel refill** | Table of fill-up events within a selected interval. Each detected fill-up records date, time and place of the event, fuel volume at the beginning and end, and total volume filled |

---

## ALERTS AND NOTIFICATIONS

Notifications can be delivered by **email or SMS**, or shown online in a popup window.

| Alert | Trigger |
|---|---|
| **Fuel fill / drain** | Sent when a vehicle is filled up or a fuel drain occurs. The alert contains when and where the event happened |
| **Fuel sensor disconnection** | Sent if the fuel sensor installed in a unit is disconnected — whether from a wiring fault or an intentional disconnection |
| **Geofence** | Generated when a unit enters, exits or stops at a particular geofence |
| **Overspeed** | Created when a speed limit violation occurs. The speed limit depends on the method for determining speeding selected in the unit's properties |
| **Panic alert** | The driver presses the panic button. The vehicle number, location and time are sent with the notification |

**The sensor disconnection alert is the one that matters most.** A fuel monitoring system that can be silently unplugged is not a fuel monitoring system, and this alert is what closes that gap.
