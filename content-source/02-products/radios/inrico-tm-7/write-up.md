# INRICO TM-7 PoC MOBILE AND BASE STATION

## THE FIXED AND VEHICLE-MOUNTED UNIT IN THE PoC RANGE

**A 12V/24V DC-powered Android 7.0 PoC base and mobile unit with dual SIM, a colour touch screen, dual-band Wi-Fi, a 5W speaker, external GPS and GSM antenna sockets and an IP54 rating.**

The Inrico TM-7 is the mobile and base station unit in the Nebsam PoC range. Unlike the handheld models it is not battery-powered — it runs from a 12V or 24V DC supply, which makes it suited to permanent installation in a vehicle cab, a control room or a dispatch desk.

# PoC OPERATION REQUIRES NETWORK COVERAGE

The TM-7 communicates through a mobile data or Wi-Fi network. Where there is no network service, the unit cannot transmit or receive. On a PoC radio the limiting factor is network coverage, not radio range.

Communication across cities, regions and countries is possible subject to network coverage and service availability in each area of operation.

## Naming note

The source heading reads "INRICO TM-7 BASE RADIO CALL WALKIE TALKIES". Brief PART 4.3 describes the TM-7 as a "mobile/base unit". "Walkie talkie" is the wrong noun for a DC-powered fixed unit and must not be used on the page. Canonical product name: **Inrico TM-7**.
