# INRICO T-521 PoC RADIO

## GLOBAL-RANGE PUSH-TO-TALK, CARRIED OVER THE CELLULAR NETWORK

**A network-connected Push-to-Talk handset with GPS, programmable emergency buttons, guard patrol mapping and a 5000mAh battery, operating on a cellular data card rather than a conventional radio frequency.**

The Inrico T-521 is a Push-to-Talk over Cellular (PoC) radio. Rather than transmitting directly to another handset over a licensed radio frequency, it carries voice across a mobile data network, so two users can talk to each other regardless of the distance between them — provided both are within cellular network coverage.

# PoC OPERATION REQUIRES NETWORK COVERAGE

The T-521 operates on a cellular data card. Where there is no mobile data service, the handset cannot transmit or receive. On a PoC radio the limiting factor is network coverage, not radio range.

Communication across cities, regions and countries is possible subject to network coverage and service availability in each area of operation.

## Claims that must not be carried over

**"Unlimited distances without interference."** The source document states that global range walkie-talkies "use a global network for communication hence enabling users to work over unlimited distances without interference". This is on the register of unpublishable claims (brief section 4.2, NEEDS_VERIFICATION register). Range on a PoC device is bounded by cellular network coverage. Every reference to range on this page is hedged as coverage-dependent and must stay that way.
