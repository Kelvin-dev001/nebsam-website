# INRICO DR10 PoC & LMR CONVERGENCE GATEWAY

## PUT YOUR EXISTING FREQUENCY RADIOS AND YOUR PoC RADIOS ON ONE NETWORK

**A gateway that bridges conventional DMR and analogue two-way radio networks with PoC global-range radio networks, so both fleets operate as one, and that can also act as a repeater to extend the range of an existing frequency radio network.**

Most organisations that adopt PoC radios already own conventional frequency radios. The Inrico DR10 exists so that investment does not have to be discarded. It connects the two systems into a single communications network, and lets a user on a frequency radio and a user on a PoC radio talk to each other.

### KEEP THE RADIOS YOU HAVE. ADD THE RANGE YOU NEED.

---

# WHAT IT DOES

The DR10 is beneficial in two ways:

**It merges networks.** It joins a commercial frequency two-way radio network to a PoC global-range server radio network, so an organisation can run both PoC radios and traditional frequency two-way radios on the same network.

**It acts as a repeater.** It extends the range of an existing traditional frequency two-way radio network, allowing frequency radios that would otherwise be out of range of each other to communicate.

The gateway uses signalling protocol technology rather than collecting and forwarding voice messages wholesale. According to the source document, gateway products that collect and transfer voice messages can take more time and cause message loss; the DR10 approach is described as making voice transmission more efficient and complete.

With the DR10 in place, a user can see the caller ID of the person they are talking to within a group, whether that person is using a global-range radio or a frequency radio.

---

# THE PROBLEM IT SOLVES

The DR10 addresses information and packet loss arising from inefficient data transmission in a hybrid network. It supports the integration of DMR, PoC and analogue radio systems into one communications network, while preserving the existing equipment.

## Items requiring verification before publication

1. `[[NEEDS_VERIFICATION: Inrico DR10 price]]` — no price appears in any supplied document. Until one is confirmed the page shows "Request price" with a WhatsApp CTA, per brief PART 10.2.
2. `[[NEEDS_VERIFICATION: does the KES 3,000 annual licence renewal apply to the DR10?]]` — the licence note in the source sits directly beneath the PoC handset pricing table and reads "Each device attracts an annual license renewal fee of KES 3,000". The DR10 document is silent on it. Do not state the fee on this page as fact, and do not omit the question either: an undisclosed recurring cost discovered after purchase is exactly the failure brief PART 10.2 warns against.
3. `[[NEEDS_VERIFICATION: Inrico DR10 supported LMR frequency bands and DMR tiers]]` — **this is the most commercially important gap on this page.** A buyer's first question is whether the gateway works with the radios they already own. The source says only that it supports "different Brands of Equipment". Obtain the supported bands, DMR tier support (Tier II / Tier III), and any compatibility list.
4. `[[NEEDS_VERIFICATION: Inrico DR10 Android version]]` — the source shows an Android badge with no version.
5. `[[NEEDS_VERIFICATION: Inrico DR10 power supply]]` — the unit has no battery, so how it is powered is a fitting requirement, not a detail.
6. `[[NEEDS_VERIFICATION: Inrico DR10 IP rating, memory and speaker]]` — undocumented.
7. `[[NEEDS_VERIFICATION: licensing implications of repeater operation]]` — the source states the DR10 "acts as a repeater for your existing traditional frequency two-way radio network". Operating a repeater on licensed frequencies may carry its own Communications Authority of Kenya licensing requirement, separate from the per-device fee. Confirm before publishing the repeater capability, because advertising a function that requires an unmentioned licence creates a compliance problem for the customer.

## Claims requiring care

The source makes a comparative claim about competing products: "Unlike most of the gateway products in the market that collect and transfer voice messages, which can take more time and cause message loss, the DR10 radio gateway simplifies the process and makes voice transmission more efficient and complete." This is a vendor claim about unnamed competitors with no measurement behind it. It is reproduced above as an attributed description of the source's position, not as a Nebsam assertion. On the public page, reframe it as a capability statement about the signalling-protocol approach rather than a comparison with "most gateway products".
