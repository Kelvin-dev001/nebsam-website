# 01. ANTI-NETWORK JAMMING

## DETECT SIGNAL INTERFERENCE. RESPOND TO THE THREAT.

Thieves may attempt to use GSM/GPS jammers to interfere with vehicle communication and tracking.

The Bluetooth Tracker is designed to **detect GSM/GPS jamming attempts and automatically activate vehicle immobilization according to its configured security logic.**

This provides an important additional layer of protection against attempts to defeat the tracking system through signal interference.

### SIGNAL JAMMING DETECTED → SECURITY RESPONSE ACTIVATED

# 02. SMART BLUETOOTH IGNITION

## YOUR SMARTPHONE BECOMES PART OF YOUR VEHICLE SECURITY

The Smart Bluetooth Ignition system adds an additional authorization layer before the vehicle can start.

The engine will not start until the owner's smartphone establishes an authorized Bluetooth connection using a **secure 4-digit PIN.**

The owner can:

* Enable or disable the feature
* Change the 4-digit PIN at any time
* Authorize engine starting through the smartphone
* Add an additional security layer beyond the conventional vehicle key

### NO AUTHORIZED BLUETOOTH CONNECTION. NO AUTHORIZED ENGINE START.

This provides an additional safeguard against unauthorized use of the vehicle, including situations where someone has access to the physical vehicle key.
